# Trayecta
Proyecto Integrador - Entornos de Desarrollo de software - Plataforma Estudiantil 

Plataforma web de trayectoria academica donde estudiantes, docentes y administrativos gestionan materias, notas y tutorias, permitiendo el seguimiento integral del desempeño academico del estudiante.

> Prototipo funcional en HTML, CSS y JavaScript. Los datos se guardan en memoria y se reinician al recargar la pagina 

## Roles y funcionalidades 
- **Estudiante:** consulta sus notas con definitiva, solicita tutorias, inscripcion y cancelacion de materias, solicitia habilitacion y revisa el estado de sus tramites.
- **Docente:** registra y publica notas por corte, ve el semamofor de rendimiento por grupo, responde solicitues de tutoria y registra asistencia y observaciones 
- **Administrativo**: gestiona materias, grupos y cupos, resuelve solicitudes, configura el periodo academico, reabre notas cerradas y consulta la auditoria

## Estructura del proyecto

- `maqueta/index.html`: estructura de las pantallas
- `maqueta/styles.css`: diseño visual
- `maqueta/script.js`: datos de prueba, vistas por rol, reglas de negocio y auditoría
- `maqueta/img/`: logo y fondos

## Como ejecutarlo 

1. Clona el repositorio: `git clone https://github.com/macohe910-spec/Trayecta.git`
2. Abre `maqueta/index.html` en el navegador. No requiere instalación ni servidor.
